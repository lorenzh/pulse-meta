2. **Typecheck.** `tsc` from `typescript 7.0.2`. Check whether the api's `typescript7` alias is needed (it exists so `typescript` stays free for tools like eslint/Biome peers). Run `tsc` under Bun (`bunx`/`bun node_modules/.../tsc`). Replace `@types/node` usage with `@types/bun` plus `@types/node` if still needed; watch version conflicts.
3. **Test mapping.** 19 files move from `node:test` to `bun:test`. Check `describe/it/test`, hooks, `t.mock`/`mock.method`, `mock.timers`, test options, and `node:assert` (may stay, `assert.rejects`/`deepStrictEqual` semantics). Do not drop or weaken tests. The `FetchLike` injection in `docs/fetch.ts` suggests little mocking; the plan verifies it.
4. **Coverage gate.** `bunfig.toml` `[test]` with `coverage = true`, lines 0.8, functions 0, and the same ignores (`**/*.test.ts`, `**/test/**`, `.build/**`, `dist/**`). Bun counts only loaded files, so the percentage may differ; verify it still passes with no new excludes. Also confirm `bun test` discovers only the intended files (the `scripts/**/*.test.ts` and `src/**/*.test.ts` set; Bun also picks up `*.spec.ts` and anything in `test/`, and Playwright specs, if any, must not be run by `bun test`). Check whether Playwright tests live in files that Bun would pick up (there is `check-a11y.ts`, a script, not a spec; confirm no `*.spec.ts`).
5. **"Playwright suite".** The issue calls it a suite; in the repo it is `scripts/check-a11y.ts` (a script driving Playwright via `@playwright/test`'s `chromium`), not a `playwright test` run. Assumption: "suite" = `check:links`, `check:budget`, `check:a11y` in CI job `site`. Run `check-a11y.ts` under Bun; Playwright under Bun is supported for the library API (not `playwright test`), so this works but must be verified in CI. Check Node-only behavior: `process.cwd()`, `node:` built-ins (kept, per AGENTS.md rule), `fetch` for docs, `esbuild` JS API under Bun (works, native binary), `renderToStaticMarkup`. Bun also reads `tsconfig` `jsx` settings and may apply them to `.tsx` at runtime, unlike Node's type stripping (Node cannot run TSX; check how the current build compiles pages, probably via esbuild). The plan must read `src/build/*` for this.
